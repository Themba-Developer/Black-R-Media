# Black R Clothing

Preview: https://black-r-clothing.mahlangu843.workers.dev

This Worker preserves and proxies the existing `black-r-website.pages.dev` Pages project, including its assets, functions, database, storage and runtime configuration. It gives the clothing website a separate named Worker and updates HTML page titles to Black R Clothing. Keep the original Pages project: it remains the backend for this preview.

Deploy from this directory using `npx --yes wrangler deploy`. A future domain can be assigned to this Worker. No domain routes or email DNS settings are configured here.
