# Black R Media

Landing page, client app listings, visitor chat and voice calls, with a protected management dashboard.

Live website: https://black-r-media.mahlangu843.workers.dev

Application source and deployment commands are in [site/README.md](site/README.md).

```sh
cd site
npm run build
npm test
npm run validate
```

For a local preview, initialise the local database and start Wrangler:

```sh
npx wrangler d1 migrations apply black-r-media --local
npx wrangler dev
```

After editing `site/web` or the API source, rebuild before previewing or deploying. `site/worker/index.js` is generated by `site/scripts/compile.mjs`; edit the source files rather than the generated entry point.

Deploy to the authorized Cloudflare account with `npm run db:migrate` followed by `npm run deploy` from `site/`.
